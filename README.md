## 特色
- 支援《雨中冒險 2》、《戴森球計劃》、《瓦爾海姆》、《GTFO》、《BONEWORKS》等更多遊戲
- 乾淨的使用者介面，旨在讓安裝模組變得盡可能簡單
- 更安全的模組安裝方式，讓您可以正常透過 Steam 遊玩遊戲
- 模組設定檔（Profiles），讓您能快速輕鬆地在不同的模組組合間切換
- 匯出設定檔以輕鬆與朋友分享您的模組和設定
- 直接從管理器下載並安裝模組
- 查看並更新任何過期的模組
- 直接從管理器編輯設定檔
- 自動更新
- 以及更多！

## 什麼是模組管理器？
其實很簡單，模組管理器就是一個能讓您更輕鬆地管理已安裝模組的應用程式。

只需點擊一下，您就可以選擇更新、啟用/停用，甚至解除安裝模組，同時在另一個設定檔中保持可用狀態。

## 安裝

### 初次安裝
#### Windows
1. 在 Thunderstore 點擊「Manual Download」。
2. 在下載的 **.zip** 檔案中，執行「r2modman Setup X.X.X.exe」（其中 X.X.X 為當前版本）。
3. 按照安裝程式的步驟進行。

#### Linux
1. 在 Thunderstore 點擊「Manual Download」。
2. 在下載的 **.zip** 檔案中，包含一個 AppImage 發布版本。

**如果您傾向於安裝特定平台的構建版本，您可以在 ebkr/r2modmanPlus 儲存庫的最新 GitHub 發布版本中找到它們**

**平台構建版本：**
 - deb
 - rpm
 - pacman
 - tar.gz

 _針對 Linux 構建版本的任何問題，應回報至 [r2modman Discord](https://discord.gg/jE2zWHY)。_

##### 注意
- 用於在 Linux 系統上強制使用 Proton 的臨時解決方案
    - 當解決方案仍在開發階段時，請在遊戲目錄中放置一個 `.forceproton` 檔案

### 更新
r2modman 會在您使用時自動下載任何可用的更新。

如果有已下載的更新，它將在您關閉應用程式時安裝。

## 幫助
### 管理器錯誤：
1. 查看 [wiki](https://github.com/ebkr/r2modmanPlus/wiki)。
2. 如果您找不到解決方案，請加入社群模組 Discord，並在適當的頻道中尋求幫助。

### 模組錯誤：
1. 加入相關的社群模組 Discord，並在適當的頻道中尋求幫助。
